# Kingdom 50/50 Strategy Clicker (Godot 4.4)

Стратегический кликер на **Godot 4.4** с разделением экрана 50/50, сеткой карты **50х50 тайлов**, перемещением камеры (ПКМ / Колесико), системой постройки и 100 уровнями прокачки.

---

## 📌 Загрузка на GitHub и Replit

### Шаг 1: Загрузка на GitHub

#### Вариант A: Через сайт GitHub (Без консоли)
1. Перейдите на [github.com/new](https://github.com/new) и создайте новый репозиторий (например, `godot-kingdom-5050`).
2. Нажмите **"uploading an existing file"** (загрузить существующие файлы).
3. Перетащите все файлы из папки `C:\Users\EGOR\.gemini\antigravity\scratch\godot_kingdom_5050` и нажмите **Commit changes**.

#### Вариант B: Через Git CLI / Git Desktop
1. Установите [Git for Windows](https://git-scm.com/download/win) или [GitHub Desktop](https://desktop.github.com/).
2. В папке проекта выполните:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Godot 4.4 strategy clicker"
   git branch -M main
   git remote add origin https://github.com/ВАШ_НИК/godot-kingdom-5050.git
   git push -u origin main
   ```

---

### Шаг 2: Импорт в Replit

1. Зайдите на [replit.com](https://replit.com/) и войдите в аккаунт.
2. Нажмите **Create Repl** (или знак **+**).
3. Выберите **Import from GitHub**.
4. Вставьте ссылку на ваш репозиторий GitHub.
5. Нажмите **Import from GitHub**. Replit автоматически подтянет файлы `.replit` и `replit.nix` с настроенным Godot 4!
